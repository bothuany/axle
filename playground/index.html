harbor-goods, a demo project: orders and shipping in Java, billing in Python

  1. Each one opens as a chain of cards: controller, services, database.

  2. Placing an order calls billing over HTTP. The dashed HTTP? link is a guess, made by matching the route, and drawn as one. The topic? link into shipping works the same way. Click a tag on a call line to open or fold that hop.

  3. Claude Code added discount codes. Added lines are green, removed lines red, and each flow is cut down to the path that reaches a change. Review changes on the bar steps through them.

  4. The agent edited the Order entity, so the first card reads Order changed, table orders and the bar lists the 4 endpoints that read or write that table.

What a browser can’t show

The Agents dock

Claude Code, Codex and any CLI run as their real tools, in terminals. The dock ranks what needs you first: an approval, a question, an error, a finished turn you have not read.

The harness map

One map of CLAUDE.md, rules, skills, subagents, hooks, MCP servers and permissions, with a health score, lint without an LLM, and what each piece costs in tokens.

Cards you can edit

On the canvas every card is a real editor with completion, hover and go to definition from your language servers. Saves go to your files, so undo and Keep stay consistent.
