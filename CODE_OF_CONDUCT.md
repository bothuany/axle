# Code of conduct

Insilode is a small project that works best when people feel safe asking questions, reporting problems and sharing ideas. This code of conduct says what we expect from everyone who takes part: in issues, pull requests, discussions and anywhere else the project is represented. It is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).

## What we expect

- Be respectful and patient. Assume good intent, and ask when something is unclear before you criticise it.
- Be specific and kind when you disagree. Argue with the idea, not the person.
- Welcome newcomers. Questions that look basic to you were not basic to you once.
- Give credit, and accept feedback gracefully.

## What is not acceptable

- Harassment, insults, threats or personal attacks, including in a code review.
- Discrimination or demeaning comments about someone's identity, background or experience level.
- Sexualised language or attention, and unwelcome contact.
- Publishing other people's private information.
- Spam, or repeatedly derailing a conversation.

## Reporting and enforcement

If something happens to you or you see it happen, tell the maintainer. Write to [@bothuany](https://github.com/bothuany) on GitHub (a private message in a GitHub discussion or a mention in the thread works), or use the private channel in [SECURITY.md](SECURITY.md) if it is sensitive. Reports are handled privately and with care for the person who reported.

The maintainer can edit or remove comments, issues and contributions that break these rules, and can warn, temporarily block or permanently ban a person from the project's spaces. The decision comes with a short explanation.

This applies to every project space and to people representing the project in public.
